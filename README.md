## 🚀 Overview

**Get Shit Done** is not just another to-do list; it's a comprehensive productivity system designed to help you focus on what truly matters. By combining the **Eisenhower Matrix** for prioritization with a **Progressive Task System** for goal breakdown, GSD ensures you're always working on high-impact tasks.

Built with a stunning **glassmorphism UI**, it provides a distraction-free environment to organize your life, track your progress, and achieve your goals.

## ✨ Key Features

### 🎯 Smart Goal Management
- **Eisenhower Matrix Integration**: Automatically categorize tasks by Urgency and Importance.
- **Visual Progress Tracking**: Real-time progress bars for every goal.
- **Categorization**: Organize goals into custom categories (Work, Personal, Health, etc.).

### 🪜 Progressive Task System
- **Step-by-Step Breakdown**: Goals are decomposed into actionable, sequential subtasks.
- **Smart Delivery**: The system presents the next logical step only after the previous one is completed, preventing overwhelm.

### 🧠 Productivity Tools
- **Focus Mode**: A dedicated, distraction-free interface for deep work sessions.
- **Daily Protocol**: specific section for your non-negotiable daily routines.
- **Dark/Light Themes**: seamless switching with persistent preference.

## 🛠 Tech Stack

Built with modern, high-performance technologies:

- **Frontend**: [React](https://reactjs.org/) (v18) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Modern CSS3 (Glassmorphism, CSS Variables, Responsive Design)
- **State Management**: React Hooks + Context API
- **Persistence**: Local Storage (Offline-first architecture)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

Follow these steps to set up the project locally.

### Prerequisites
- Node.js (v16.0.0 or higher)
- npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/K11mito/Goal-tracking-and-daily-routine-app.git
    cd Goal-tracking-and-daily-routine-app
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Open in Browser**
    Visit `http://localhost:5173` to view the app.
