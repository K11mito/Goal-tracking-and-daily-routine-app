# Get Shit Done

A productivity app for goal tracking and daily task management with an Eisenhower Matrix prioritization system.

## Features

- **Goal Management**: Create goals with categories, importance levels, and due dates
- **Progressive Task System**: Each goal is broken down into sequential, actionable steps
- **Eisenhower Matrix**: Tasks are color-coded by urgency and importance
- **Progress Tracking**: Visual progress bars show completion status for each goal
- **Focus Mode**: Distraction-free mode to concentrate on a single task
- **Dark/Light Theme**: Clean glassmorphism UI with theme toggle

## Tech Stack

- React + TypeScript
- Vite
- Local Storage for persistence

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```
